# Пользовательские сценарии

## Ключевой сценарий: аренда оборудования

**Актор:** студент или сотрудник университета

1. Открывает каталог оборудования
2. Фильтрует по категории и выбирает устройство
3. Смотрит карточку: фото, состояние, условия аренды (срок, залог, требования)
4. Выбирает период аренды, система проверяет доступность
5. Отправляет заявку (статус `pending`)
6. Администратор одобряет заявку (статус `approved`)
7. Пользователь видит в личном кабинете активную аренду и статус возврата

**Альтернативы:**
- Оборудование занято на выбранный период: пользователь встаёт в очередь ожидания
- Администратор отклоняет заявку (статус `rejected`)
- Пользователь отменяет заявку (статус `cancelled`)

## Статусы бронирования

`pending → approved → issued → returned`, а также `rejected`, `cancelled`, `overdue`
